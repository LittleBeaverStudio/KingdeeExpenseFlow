# 报销制度规则（随 skill 分发，agent 对话中主动提醒）

> 本文件随 skill 分发给外部用户，不内置到对话背景。agent 在帮用户提交单据/上传发票时，按下列规则**主动核对并提醒**，不打断流程但必须提示风险。

## 一、业务招待费

- **必须上传 CEO 同意的微信截图**作为附件（走"附件"，不是收票信息）。
- 缺失截图 → 提醒："业务招待费需提供 CEO 微信同意截图，否则财务会驳回。请上传截图。"
- 金额较大（如 > 2000 元）建议额外确认审批层级。

## 二、差旅费（按城市分级限额）

> 城市分级与限额由使用方在 `config` 或本文件 `CITY_LIMITS` 处按本公司制度填写。下列为**模板占位**，实际数值以公司制度为准。

```yaml
CITY_LIMITS:
  一线城市:   { 住宿: 500, 餐饮: 200, 交通: 实报实销 }
  二线城市:   { 住宿: 350, 餐饮: 150, 交通: 实报实销 }
  其他城市:   { 住宿: 250, 餐饮: 100, 交通: 实报实销 }
```

- 员工提交差旅报销时，agent 提取出差城市 + 各类票据金额，逐类比对限额。
- **超标** → 提醒："{城市} 住宿上限 {N} 元/晚，本单 {M} 元超标 {D} 元，是否拆单或申请特批？"
- 交通以票据为准；无票/定额需说明。

## 三、发票通用要求

- 购方抬头须 = 申请组织全称（如"示例科技有限公司"），税号 `91110000000000000X`。
- 抬头不符 → 拦截："发票购方为 {X}，与组织 {Y} 不一致，请重开或更换发票。"
- 发票须清晰、完整、未涂改；模糊/缺角 → 打回重拍。

## 四、行程单 vs 发票（双算预警，强制）

- 行程单（机票/火车票行程单、住宿清单）**一律传附件**，不传收票信息。
- 若用户把行程单传到收票信息 → 警告："行程单若传入收票信息，系统会 OCR 识别金额，与发票重复计入，汇总金额虚高，可能被财务驳回。建议改传附件。仍要传收票信息请确认，我将展示汇总金额供你核对。"
- 用户坚持 → 计算并展示**汇总金额**，明确标注风险，记录操作。

## 五、提醒话术模板

| 场景 | 提醒 |
|---|---|
| 招待费缺 CEO 截图 | "业务招待费需上传 CEO 微信同意截图，否则财务会驳回。" |
| 差旅住宿超标 | "{城市} 住宿上限 {N}/晚，本单 {M} 超标 {D}，是否拆单/特批？" |
| 发票抬头不符 | "发票购方 {X} ≠ 组织 {Y}，请重开。" |
| 行程单误传收票信息 | "行程单请传附件，避免与发票重复计入被驳回。" |
| 发票金额 < 报销金额 | "收票信息里没有有效发票，发票金额小于报销金额，请上传发票到收票信息。" |
